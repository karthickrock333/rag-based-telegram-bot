## 📌 Overview

This project implements a **Mini Retrieval-Augmented Generation (RAG) Telegram bot**.
The bot answers user questions by retrieving relevant information from local documents and generating responses using **Google Gemini API**.

---

## 🚀 Key Capabilities

- Telegram bot interface
- Document chunking and embedding
- Semantic retrieval from local documents
- Context-aware answer generation using Gemini
- Lightweight SQLite storage
- Compatible with restricted corporate Windows machines

---

## 🧠 High-Level Flow

Telegram User → Backend → Document Retrieval → Gemini LLM → Telegram Response

---

## 🛠 Tech Stack

- Python
- python-telegram-bot
- Google Gemini API
- SQLite
- Retrieval-Augmented Generation (RAG)
